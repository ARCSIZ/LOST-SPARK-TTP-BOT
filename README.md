# Discord Registration Bot

Бот для регистрации персонажей с системой ролей и модерации заявок.

## 📋 Функционал

### Команды для всех:
- `/registration` или `/регистрация` - Открыть форму регистрации персонажа

### Команды модератора:
- `/delete_character` - Удалить персонажа по Steam ID
- `/registered_list` - Список зарегистрированных персонажей
- `/list_staff` - Список персонала

### Команды администратора:
- `/set_registration_channel` - Установить канал для регистрации
- `/set_applications_channel` - Установить канал для заявок
- `/add_moderator` - Выдать права модератора
- `/remove_moderator` - Снять права модератора
- Все команды модератора

### Команды владельца:
- `/view_logs` - Просмотр логов действий
- `/add_admin` - Выдать права администратора
- `/remove_admin` - Снять права администратора
- Все команды администратора и модератора

### Команды разработчика:
- `/add_owner` - Выдать права владельца
- `/remove_owner` - Снять права владельца
- `/sync` - Синхронизировать команды бота
- `/bot_stats` - Статистика бота
- Все команды владельца, администратора и модератора

## 🚀 Инструкция по установке

### Шаг 1: Создание бота на Discord Developer Portal

1. Перейдите на https://discord.com/developers/applications
2. Нажмите **"New Application"** (синяя кнопка справа вверху)
3. Введите название бота и нажмите **"Create"**

### Шаг 2: Настройка бота

1. В левом меню выберите **"Bot"**
2. Нажмите **"Add Bot"** → **"Yes, do it!"**
3. **ВАЖНО:** Включите следующие опции в разделе **"Privileged Gateway Intents"**:
   - ✅ PRESENCE INTENT
   - ✅ SERVER MEMBERS INTENT
   - ✅ MESSAGE CONTENT INTENT
4. Нажмите **"Reset Token"** и скопируйте токен бота

### Шаг 3: Получение токена

1. На странице **"Bot"** нажмите **"Reset Token"**
2. Скопируйте показанный токен (он показывается только один раз!)
3. Вставьте токен в файл `bot.py` в переменную `TOKEN`:
   ```python
   TOKEN = "ваш_токен_здесь"
   ```

### Шаг 4: Получение вашего Discord ID

1. Откройте Discord
2. Перейдите в **Настройки** → **Расширенные**
3. Включите **"Режим разработчика"**
4. Нажмите правой кнопкой мыши на своё имя пользователя
5. Выберите **"Копировать ID"**
6. Вставьте ID в файл `bot.py` в список `DEVELOPER_IDS`:
   ```python
   DEVELOPER_IDS = [123456789012345678]  # Ваш ID
   ```

### Шаг 5: Приглашение бота на сервер

1. В левом меню выберите **"OAuth2"** → **"URL Generator"**
2. В разделе **"SCOPES"** выберите:
   - ✅ bot
   - ✅ applications.commands
3. В разделе **"BOT PERMISSIONS"** выберите:
   - ✅ Administrator (или выберите нужные права отдельно)
4. Скопируйте сгенерированную ссылку внизу страницы
5. Откройте ссылку в браузере и добавьте бота на ваш сервер

### Шаг 6: Установка Python и зависимостей

1. Убедитесь, что у вас установлен Python 3.8+
2. Откройте терминал/командную строку в папке с ботом
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

### Шаг 7: Запуск бота

```bash
python bot.py
```

## ⚙️ Первоначальная настройка на сервере

После запуска бота выполните следующие команды:

1. **Установите канал для регистрации:**
   ```
   /set_registration_channel #канал-регистрации
   ```

2. **Установите канал для заявок:**
   ```
   /set_applications_channel #заявки-модераторам
   ```

3. **Назначьте администраторов и модераторов:**
   ```
   /add_admin @пользователь
   /add_moderator @пользователь
   ```

```
Разработчик (DEVELOPER_IDS)
    └── Владелец (owners)

            └── Модератор (moderators)
                └── Обычный пользователь
```

Каждый уровень имеет доступ ко всем командам нижестоящих уровней.

## ❓ Решение проблем

### Команды не появляются
- Подождите до 1 часа (Discord кэширует команды)
- Используйте команду `/sync` для принудительной синхронизации
- Убедитесь, что бот имеет права `applications.commands`

### Бот не отвечает
- Проверьте, что токен введён правильно
- Проверьте, что включены все Intents в Developer Portal
- Проверьте консоль на наличие ошибок

### Ошибка при регистрации
- Убедитесь, что настроены каналы для регистрации и заявок
- Проверьте, что бот имеет права отправлять сообщения в эти каналы
